# Changes (2026-01-20)

This document summarizes the repository modernization completed on or before 2026-01-20 (branch `feature/rename-roles`).

Summary
-------
- Role namespace renames: many roles were renamed into a consistent convention (`ansible_dev_node_*`, `platform_*`, `scenario_*`, `integration_*`, `os_*`) to improve discoverability and standardize responsibilities.
- Removal of `/rhis` path segments in `roles/` (e.g., `/opt/rhis/inventory` → `/opt/inventory`). This was applied only to files under `roles/`.
- Merged network defaults from `roles/ansible_dev_node_env_config/network_defaults.j2` into `roles/platform_libvirt_setup/defaults/main.yml` and added `roles/platform_libvirt_setup/README.md` with usage examples.
- Added persistent marker behavior to platform roles so setup tasks can be skipped once applied:
  - Marker files under `/var/lib/rhm/` (e.g., `/var/lib/rhm/platform_libvirt_setup_done`).
  - Facts files under `/etc/ansible/facts.d/` (e.g., `rhm.fact`, `rhm_host_provisioning.fact`, `rhm_vmprov.fact`).
  - Roles with markers: `platform_libvirt_setup`, `platform_host_provisioning`, `platform_libvirt_vm_provisioner`.
- Removed `roles/ansible_dev_node_legacy_archive` (legacy archive no longer used).
