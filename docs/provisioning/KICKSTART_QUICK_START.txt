HOW TO USE
================================================================================

1. CONFIGURE THE ROLE

Add to your Satellite deployment playbook:

---
- name: Deploy Satellite Kickstarts
  hosts: scenario_satellite
  roles:
    - role: satellite_kickstart_config
      vars:
        satellite_url: "https://scenario_satellite.prod.example.com"
        satellite_username: "admin"
        satellite_password: "{{ vault_satellite_admin_password }}"
        create_provisioning_templates: true
        upload_kickstart_files: true

2. RUN THE PLAYBOOK

ansible-playbook redhat_management-site.yml

3. VERIFY KICKSTART FILES

# Check files exist on Satellite
ls -la /var/lib/foreman/public/kickstarts/

# Verify content
grep "RHEL 9 BaseOS Minimal" /var/lib/foreman/public/kickstarts/rhel9-baseos-minimal.ks

4. USE IN SATELLITE PROVISIONING

- Navigate to: Hosts → Provisioning Templates
- Create platform_provisioning host entry
- Select Operating System (RHEL 9 or RHEL 10)
- Assign appropriate template
- Configure network and activation key
- Boot via PXE or use kickstart URL

5. PROVISION A HOST

Boot system via PXE:
- System downloads kickstart from Satellite
- Anaconda performs automated installation
- System registers with activation key
- Ready for management

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "Unable to find kickstart file"
SOLUTION:
- Verify Satellite web server: systemctl status foreman
- Check file permissions: ls -la /var/lib/foreman/public/kickstarts/
- Verify URL in PXE config
- Check Satellite firewall

PROBLEM: Package installation fails
SOLUTION:
- Verify RHEL repositories enabled in Satellite
- Run satellite_content_config to enable repos
- Check activation key has repo subscriptions
- Sync repositories via Satellite

PROBLEM: System doesn't register
SOLUTION:
- Verify activation key configuration
- Check key has correct subscriptions
- Test manually: subscription-manager register --org="..." --activationkey="..."

PROBLEM: Network configuration issues
SOLUTION:
- Verify DHCP server running
- Check PXE boot network config
- Modify kickstart for static IP if needed
- Edit 'network' section in defaults/main.yml
