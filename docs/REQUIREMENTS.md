# Requirements Checklist

- RHEL 8/9 or compatible
- Libvirt installed (`libvirt`, `python3-libvirt`, `virt-install`)
- Ansible Automation Platform 2.x ([Download](https://access.redhat.com/downloads/content/480))
- Red Hat Insights client (`insights-client`)
- Python 3.x
- Git
- Required Ansible collections:
  - community.general
  - ansible.posix
  - ansible.controller
- GitHub account and repo for playbooks/roles
- All credentials stored in Ansible Vault or environment variables
